# Pawon Mantyasih (prototipe)

Game edukasi budaya dan kuliner Mantyasih (Magelang). Hasil build web yang bisa langsung dicoba di browser.

- Mainkan: buka halaman ini di GitHub Pages (tautan ada di bagian About repositori).
- Uji per misi tanpa mulai dari awal: `panduan.html`, atau tautan `?mission=M01` sampai `?mission=M08`.
- Pratinjau karakter: `karakter.html`.

Catatan: seluruh teks pada versi ini adalah placeholder dan belum divalidasi narasumber.
